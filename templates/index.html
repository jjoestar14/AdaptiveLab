Prinsip Matematis & Teori Adaptive Gaussian Thresholding

1. Rumus Ambang Batas Spasial Lokal T(x, y)

Tidak seperti metode global seperti Otsu yang menentukan satu nilai ambang tunggal untuk seluruh citra, Adaptive Gaussian Thresholding menghitung nilai ambang dinamis untuk setiap piksel (x, y) berdasarkan bobot sebaran normal Gaussian pada lingkungan tetangga berukuran N × N:

T(x, y) = μG(x, y) − C

Biner(x, y) = 255 jika I(x, y) > T(x, y), selain itu 0

di mana μG(x, y) adalah konvolusi citra keabuan dengan kernel Gaussian 2D, dan C adalah konstanta offset pengurang ambang.

2. Pembangunan Kernel Gaussian 2D

Kernel Gaussian memberikan bobot spasial tertinggi pada piksel pusat (jarak r = 0) dan meluruh secara eksponensial ke arah tepi jendela:

G(x) = exp( −0.5 × (x / σ)2 )
σ = 0.3 × ((N − 1) × 0.5 − 1) + 0.8
K2D = (G ⊗ GT) / ∑ K2D

Sifat Gaussian menghasilkan transisi ambang batas lokal yang jauh lebih halus dan bebas efek artefak batas kotak (blocking artifacts) dibandingkan Adaptive Mean.

3. Arti Fisis Parameter

  • Block Size (N): Rentang radius pengaruh pencahayaan lokal. Nilai N harus lebih besar dari ketebalan goresan teks dan ukuran spasi karakter agar piksel latar sekitar teks masuk ke dalam perhitungan rata-rata.
  • Konstanta C: Mengontrol sensitivitas deteksi. Nilai C positif menekan sensitivitas agar tekstur kertas atau noise mikro tidak terdeteksi sebagai teks. Jika C terlalu besar, goresan teks tipis akan hilang (False Negative). Jika C terlalu kecil atau negatif, noise bintik akan bermunculan di area kosong (False Positive).

4. Kapan Metode Ini Sangat Cocok & Batasannya

Kelebihan Utama:

  • Sangat tangguh terhadap dokumen dengan gradien bayangan kuat, pencahayaan ponsel miring, dan noda kelembapan kertas tua.
  • Mempertahankan keterbacaan teks di area yang gelap maupun terang secara serentak.

Keterbatasan & Solusi:

  • Pada area seragam murni (blank area), perbedaan intensitas acak kecil dapat terpicu jika C mendekati 0. Solusi: Gunakan nilai C yang cukup (≥ 4-8) dan aktifkan pasca-proses penghapusan komponen kecil.
  • Sensitif terhadap noise impulsif salt-and-pepper. Solusi: Aktifkan pra-proses Median Filter sebelum thresholding.
